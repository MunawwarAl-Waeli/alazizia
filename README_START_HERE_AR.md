# البدء السريع — مشروع العزيزية للمظلات والسواتر

هذه الحزمة هي النسخة النهائية من موقع **شركة العزيزية للمظلات والسواتر**. المشروع مبني بـ **React + Vite** ويعمل كتصدير ثابت؛ لا يحتاج إلى Express أو Node.js Server أو قاعدة بيانات وقت النشر.

## ما الذي يوجد في الحزمة؟

| المجلد أو الملف | الغرض |
|---|---|
| `client/` | كود واجهة React والصفحات والمكونات والتنسيقات. |
| `static-assets/` | الصور وملف بيانات الخدمات المطلوبان وقت البناء. |
| `dist/` | نسخة جاهزة للرفع المباشر إلى Hostinger. |
| `hostinger/.htaccess` | قواعد Apache لمسارات React ورؤوس الحماية. |
| `scripts/` | خطوات تحقق وتجهيز الأصول وقت البناء. |
| `HOSTINGER_STATIC_DEPLOYMENT_AR.md` | شرح تفصيلي للنشر على Hostinger. |
| `SECURITY_AUDIT_AR.md` | تقرير التدقيق الأمني والإعدادات المطبقة. |

## تعديل الموقع محليًا

تحتاج إلى Node.js 20 أو أحدث وpnpm 10 أو أحدث.

```bash
pnpm install --frozen-lockfile
pnpm dev
```

بعد الانتهاء من أي تعديل، أنشئ نسخة الرفع الجديدة:

```bash
pnpm build
```

سيُنشأ أو يُحدّث مجلد `dist/` تلقائيًا، بما في ذلك الصور وبيانات الخدمات داخل `dist/media/`.

## الرفع إلى Hostinger

ارفع **محتويات** `dist/` مباشرةً إلى `public_html/`، وليس المجلد `dist` نفسه. تأكد من رفع الملف المخفي `.htaccess` ومن تفعيل SSL للنطاق. لا تشغّل `npm start` ولا ترفع `node_modules/`.

> لمزيد من التفاصيل، راجع `HOSTINGER_STATIC_DEPLOYMENT_AR.md`.
